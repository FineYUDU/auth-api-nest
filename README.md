<h1 align="center">Auth Api Nestjs</h1>

## Description

Repository for authentication for users.

## Project setup
#### 1. Clone project
```
$ git clone 
```
#### 2. install all dependencies
```
$ npm install
```
#### 3. Clone file ```.env.example``` and renamed to ```.env```
- Change values of the variables in the .env.
-  Run DBA

```
$ docker-compose up -d
```
#### 4. Run project
```
$ npm run start:dev
```
